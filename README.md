# ONE DAY — Windows Builds

원데이(ONE DAY) Windows x64 실행 빌드를 보관하는 저장소입니다.

## 다운로드

[Releases](https://github.com/l3in99/WWE/releases)에서 원하는 버전의 ZIP을 다운로드하세요.

- **최적화 버전 · 2026-11-18**: 미사용 이미지 정리와 이미지 압축을 적용한 최신 빌드. 압축을 풀고 `OneDay.exe`를 실행합니다.
- **이전 버전 · 2026-11-17**: 최적화 이전의 기존 빌드를 비교용으로 보관합니다. 압축을 풀고 `wwe.exe`를 실행합니다.

ZIP 전체를 압축 해제한 뒤 실행하세요. 실행 파일과 `_Data` 폴더, DLL 등 함께 제공되는 파일을 같은 폴더에 유지해야 합니다.

각 릴리스에는 다운로드 파일의 무결성을 확인할 수 있는 SHA-256 체크섬이 함께 제공됩니다. Unity 개발용 디버그 정보(`DoNotShip`)는 배포 패키지에서 제외했습니다.

이 저장소의 릴리스 파일은 실행용 빌드이며 Unity 프로젝트 원본이 아닙니다.
